# منصة الأفق لإدارة الجمعية — الإصدار 5.1

منصة هاتفية لإدارة جمعية الأفق للرياضات الجوية والجبلية.

## نطاق الإصدار
- سنة التأسيس 2025 بتاريخ 31/08/2025.
- 16 عضوًا مؤسسًا.
- لا توجد اشتراكات مدفوعة للأعضاء حتى الآن.
- حركة تاريخية مؤكدة: هبة 1,000 دج من رئيس الجمعية.
- مصاريف بنكية مؤكدة: 595 دج.
- الرصيد التاريخي: 405 دج.
- تمييز البيانات الرسمية عن البيانات التجريبية.
- مركز حوكمة وجودة بيانات.
- السجل المالي الموحد، العضويات، الأنشطة، المشاركات، الحضور، التكوين، البريد، المعدات والتقارير.

## التخزين الحالي
البيانات محفوظة محليًا في متصفح الجهاز (localStorage). النسخة المركزية السحابية والصلاحيات متعددة المستخدمين مرحلة لاحقة تتطلب قاعدة بيانات وخدمة مصادقة.

## النشر
المشروع static ويمكن نشره على Vercel أو أي استضافة للملفات الثابتة.
