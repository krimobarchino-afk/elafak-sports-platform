# منصة جمعية الأفق — إعادة البناء

الموقع العام لجمعية الأفق الولائية للرياضات الجوية والجبلية، ولاية الشلف، الجزائر.

## المرحلة الحالية
- صفحة تعريفية عربية باتجاه RTL وتصميم متجاوب.
- نموذج طلب الانخراط متصل بـ Supabase ويحفظ الطلبات للمراجعة.
- لا توجد حتى الآن لوحة موظفين أو نظام دخول وأدوار.
- إرسال طلب الانخراط لا يعني قبوله ولا ينشئ حسابًا.
- لا يوجد نظام رسوم أو باقات مفعّل.

## قرارات المشروع
- بناء المنصة تدريجيًا واختبار كل مرحلة قبل الانتقال إلى التالية.
- إبقاء نظام الباقات والاشتراكات مجمّدًا حتى مصادقة الجمعية العامة.
- عدم استخدام البريد الشخصي للمسؤولين كاسم دخول مفروض عليهم؛ مدير الموقع يحدد أسماء المستخدمين والأدوار.
- استخدام Supabase Auth والمصادقة الخادمية بدل تخزين كلمات المرور في جداول التطبيق أو التحقق منها في المتصفح.
- تطبيق الصلاحيات على مستوى قاعدة البيانات والخادم، وليس الواجهة فقط.

## تشغيل الواجهة
واجهة ثابتة قابلة للنشر على Vercel باستخدام إعدادات المشروع الافتراضية.

## التهيئة والأمان
راجع [دليل إعداد Supabase](supabase/SETUP.md) قبل تغيير السياسات أو إعداد حسابات الموظفين. لا تضع أي مفتاح سري في المستودع.
