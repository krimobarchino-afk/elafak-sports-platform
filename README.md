# منصة جمعية الأفق — إعادة البناء

الموقع العام لجمعية الأفق الولائية للرياضات الجوية والجبلية، ولاية الشلف، الجزائر.

## المرحلة الحالية
- صفحة تعريفية مستقلة باللغة العربية واتجاه RTL.
- تصميم متجاوب للهاتف والحاسوب.
- قائمة تنقل للهاتف ورسالة توضيحية لطلب الانخراط.
- لا توجد منظومة دخول أو تخزين بيانات أو رسوم/باقات في هذه المرحلة.

## قرارات المشروع
- بناء المنصة تدريجيًا واختبار كل مرحلة قبل الانتقال إلى التالية.
- إبقاء نظام الباقات والاشتراكات غير مفعّل إلى حين مصادقة الجمعية العامة.
- عدم جمع بيانات الأعضاء عبر واجهة غير متصلة بخلفية آمنة.
- إعداد الصلاحيات والعضوية والمالية لاحقًا وفق القرارات المتفق عليها.

## التشغيل
واجهة ثابتة قابلة للنشر على Vercel باستخدام إعدادات المشروع الافتراضية.
