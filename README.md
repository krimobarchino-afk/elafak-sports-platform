# منصة جمعية الأفق — إعادة البناء

الموقع العام لجمعية الأفق الولائية للرياضات الجوية والجبلية، ولاية الشلف، الجزائر.

## ما هو موجود
- صفحة تعريفية عربية RTL ومتجاوبة، ونموذج طلب انخراط يرسل إلى Edge Function للتحقق من المدخلات والحد من الإرسال الآلي والمتكرر.
- بوابة موظفين في `/staff.html` لدخول اسم المستخدم وكلمة المرور، ومراجعة طلبات الانخراط وفق الدور، وإدارة حسابات الموظفين من حساب مدير الموقع.\n- فضاء التسيير الموحد في `/management.html`: سجل مالي موحد مع إقفال السنوات، وإدارة الأنشطة والميزانيات المخططة/الفعلية، وجرد المعدات، ومحاضر الاجتماعات والقرارات، وتصدير CSV ونسخ JSON، وسجل تغييرات إداري.
- Supabase Auth للمصادقة، وEdge Functions خادمية لإدارة الحسابات واستقبال طلبات الانخراط، وسياسات RLS لصلاحيات مراجعة الطلبات.
- إرسال طلب الانخراط لا يعني القبول ولا ينشئ حسابًا.
- لا يوجد نظام رسوم أو باقات مفعّل.

## قرارات المشروع
- أسماء المستخدمين المقترحة قابلة للتغيير من مدير الموقع.
- الأدوار: مدير الموقع، الرئيس، نائب الرئيس، الأمين العام، أمين المال، نائب الأمين العام، نائب أمين المال، المدير التقني.
- لا يُستخدم البريد الشخصي كاسم دخول، ولا تحفظ كلمات المرور في جداول التطبيق أو المستودع.
- تظل الرسوم والباقات مجمّدة حتى مصادقة الجمعية العامة.

## التهيئة
راجع [دليل إعداد Supabase](supabase/SETUP.md) لإنشاء أول مدير من لوحة Supabase، ثم إنشاء الحسابات المتبقية واختبار الصلاحيات. لا تعتبر المنصة جاهزة للاستخدام الرسمي قبل اختبار الأدوار.
